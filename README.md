# Lexicon Labyrinth

A playful, front-end JavaScript app that serves up invented words with funny definitions, pronunciation guides, parts of speech, and example sentences. Click **Find another word** to explore the collection, or use **Copy** to copy a word and its definition.

## Run locally

No build tools or dependencies are required. Open `index.html` in a browser to try the app. The app is made with plain HTML, CSS, and JavaScript.

## Live site

The game runs live at [words.numbercatalog.org](https://words.numbercatalog.org).

## Future improvements

- Grow the word collection or generate new words and definitions dynamically.
- Add categories, search, and filters to explore different kinds of nonsense.
- Let visitors save favorite words and share them with friends.
- Add more accessibility and interaction polish, such as keyboard shortcuts and improved copy feedback.
